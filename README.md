
🌟 Employee Management System – Python Tkinter

Welcome to my repository for the Employee Management System, a desktop application built using Python and Tkinter to manage employee data efficiently. This project demonstrates hands-on skills in GUI development, database integration, and practical software design.


📁 Included Features

🔹 Employee CRUD Operations
A fully functional interface to add, update, delete, and view employee records**. Includes a searchable Treeview for easy record management.

✨ Enhanced with MySQL database integration for storing employee details securely and persistently.

🔹 Report Generation
Generate detailed employee reports including attendance, salary, and progress. Reports can be exported as PDFs and shared via email.

🔹 Search and Filtering
Easily search, filter, and sort employee records to find relevant information quickly.

---

 🛠 Technologies Used

* Python
* Tkinter (Graphical User Interface)
* MySQL (Database)
* ReportLab / Matplotlib (for PDF reports and charts)


🎯 Purpose

This project was created to streamline employee data management in small to medium organizations, providing a user-friendly GUI with real-world database integration. It helped me gain hands-on experience with:

* GUI development using Tkinter
* Database connectivity and CRUD operations
* Report generation and email automation
* Software design principles and practical problem-solving
